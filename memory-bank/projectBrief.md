# memory-bank/projectBrief.md

## 🎯 显式愿景 (Vision)
为小学家长提供一个极简、直观、即点即看的 PC 网页端 A4 纸质生字练习与互动游戏设计工具。通过同步人教版教材的科学字库、高度可控的字帖视觉排版以及创新的“汉字部件拆解拼接游戏”生成引擎，将传统的枯燥识字转变为高参与度的亲子动手益智游戏，全面提升小学生的汉字结构认知与书写规范。

## 🚧 显式边界 (Core Scope)
* **教材同步字库管理**：严格对齐人教版小学语文（1~6年级、上下册、单元级）多级联动筛选，提供生字的单选、多选、全选快捷操作。
* **高阶字帖视觉矩阵**：支持田字格底纹显隐、标准拼音标注显隐、笔顺分解图引导显隐、以及文字与描红颜色的自定义配置。
* **部件拆解游戏引擎**：基于结构字库自动将目标汉字拆解为标准偏旁/部件，并自动排版生成带虚线裁剪辅助线的 A4 拼图游戏纸面。
* **所见即所得打印控制**：实现完全等比例的 A4 网页预览区，支持全配置项实时响应（WYSIWYG），一键触发浏览器原生 `window.print()`，确保零拉伸、零错页、零溢出的硬性 A4 物理适配。

## 🛑 负向约束 (Out of Scope / Anti-Goals)
* **不做多端与移动端适配**：本版本坚决不做手机、Pad等移动端屏幕的排版与交互适配，锁定 PC 浏览器为唯一合法运行环境。
* **不做在线交互式游戏**：不提供学生在屏幕上拖拽拼字、在线描红等软件层面的数字化游戏交互，所有游戏和练习均通过 A4 纸张打印后离线进行。
* **不做非人教版教材内容**：本版本拒绝接入非人教版（如苏教版、北师大版等）的字库数据，仅在数据模型设计上保留扩展槽。
* **不做后端云端存储与用户系统**：无注册登录，不保存家长的历史配置或自定义字单，所有状态均在前端运行时维持。
