# 架构师红队审查与技术选型白皮书 (Print4A 特化版)

## 🔍 核心技术攻坚与红队论证
### 1. 底层物理与生态墙
- 传统 Web 字体文件（TTF/WOFF）只存储最终字形轮廓，不暴露笔画先后顺序与独立 SVG 路径，此为浏览器生态之硬物理墙。

### 2. 行业标准选型对比
- **方案 A（Canvas/SVG 矢量重绘）**：如 `Hanzi-Writer`。利用开源矢量笔画 JSON 数据，按步渲染路径。优点：100% 动态联动，字形标准，不依赖庞大字体包。
- **方案 B（专用字帖分步字体包）**：通过特殊映射加载包含笔顺的 TTF。缺点：字体包体积过大（>10MB），带有版权风险。

### 3. 架构选型结论
- 决定采用 **方案 A (Hanzi-Writer 引擎)**。数据契约锁死为 Canvas/SVG 挂载容器，彻底废除任何尝试用 CSS/DOM 绝对定位拼凑离散字符的低效黑产方案。
